# Practical and Error-Lab Prompt

Create labs only for the named chapter and listed subtopics. Provide a safe public or synthetic dataset specification, setup, objective, inputs, tasks, expected outputs, validation checks, error injection plan, troubleshooting prompts, solution criteria, and extension.

The error lab must contain realistic but clearly controlled defects such as wrong data types, missing values, duplicate keys, incorrect joins, invalid formulas, leakage, broken configuration, or unsafe permissions. Do not include secrets or real personal data.
