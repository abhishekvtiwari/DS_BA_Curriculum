# Chapter 40 · Time Series & Forecasting

Run this chapter's notebook (`ch40.ipynb`) from this folder. It reads two datasets that the companion scripts build next to it:

```
python ../generate_riverstone_demand.py     # writes ../demand/weekly_demand.csv and monthly_demand.csv
python ../generate_riverstone_sensors.py    # writes ../sensors/machine_readings_week.csv
```

Both generators are seeded (20240 and 20241), so they always write the same numbers. Section 40.0 of the chapter explains each step, and section 40.5 installs Prophet (`python -m pip install prophet`).

Riverstone Supplies is fictional; every name and number is invented.
