# 3 October 2026 · Section 74.8, the predict-the-number round

**Section 74.8, "Predict the number: what the library did that you did not ask for."** 5,792 words,
10 core questions (Q74-037 to 046) and 10 rapid-fire rows (Q74-047 to 056), taking the chapter from
36 questions to 56. Nothing renumbered.

Every question is a model that trains without a warning, scores plausibly, and reports a number
that is not what the analyst thinks it is, because scikit-learn made a choice silently:

| | |
|---|---|
| Q74-037 | `.score()` is accuracy on a classifier and R² on a regressor: 0.9222 and 0.9365, not comparable |
| Q74-038 | R² is −3.0 for a model worse than the mean; 0 is the baseline, not the floor |
| Q74-039 | AUC is identical to six decimals under halving, cubing and log; accuracy falls 0.9222 to 0.6500 |
| Q74-040 | No `stratify`: the test set runs from 4% to 10% positive, 8 positives in one split and 20 in another |
| Q74-041 | `cv=5` does not shuffle: 0.930 against 0.997 on a sorted target |
| Q74-042 | `LogisticRegression()` is penalised at `C=1.0`: max coefficient 1.403 against 7.677 unpenalised |
| Q74-043 | A permuted target gives AUC 0.47, not 0 — and a high value proves leakage |
| Q74-044 | A pure noise column scores 0.0271 and ranks above a real feature |
| Q74-045 | Two features correlated at 0.999948 get coefficients −1.170 and +4.166, summing to the true 3 |
| Q74-046 | k-means on unscaled age and income clusters on income alone; variance ratio 209 million to one |

## Two questions the runs killed

1. **`cross_val_score(cv=5)` on a sorted target does nothing visible for a classifier.** scikit-learn
   quietly uses `StratifiedKFold` for classifiers, so the folds are balanced and the score is
   unchanged. The question only works on a regressor, where `cv=5` is plain `KFold` — and that
   asymmetry is now the point of the question rather than an obstacle to it.
2. **The regularisation contrast was too weak to see.** On 600 samples and 8 features, `C=1.0` and
   `C=1e6` gave 0.470 and 0.477. Rebuilt on 60 samples and 40 features, where the default shrinks
   the largest coefficient from 7.677 to 1.403 and the effect is unmistakable.

One claim was softened after checking: `SVC().probability` reports `'deprecated'` in scikit-learn
1.9.0, as does `LogisticRegression().penalty`, so the rapid-fire row now states only what was
observed — that `predict_proba` raises `AttributeError` on a default `SVC` — rather than describing
a parameter whose status is changing.
