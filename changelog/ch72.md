## Verification

NumPy 2.4.3, pandas 3.0.2, Python 3.12. Every figure printed came from a run.

**Two things the runs corrected.** My first view-against-copy test built two separate arrays, so it
showed no sharing and I would have published the wrong conclusion about the thing the question is
about. Rebuilt, it shows the view clearly. And the sort-stability claim was asserted before it was
demonstrated: on 8 rows quicksort preserved order, which proved nothing. On 1,000 rows it reorders
tied rows visibly — and the rapid-fire row now says both, because *looking stable on small data* is
exactly why that bug survives testing.

**No overlap with the existing chapter.** Mutable defaults, `is` against `==`, shallow copies, the
loop of lambdas, the predict-the-output set, generators, decorators, `SettingWithCopyWarning`,
groupby, merge, `.apply` speed and missing data are all already there and none is repeated.
Q72-069 and Q72-079 deliberately point back at Q72-036 and Q72-001 rather than re-teaching them.
