# Assessment Validation Rubric

An assessment bank is valid only when every item passes the following checks.

| Check | Requirement | Evidence | Blocker? |
|---|---|---|---|
| ID uniqueness | No duplicate item IDs | Duplicate scan | Yes |
| Topic mapping | Every item maps to a listed topic/subtopic ID | Mapping report | Yes |
| Answer correctness | Answer is technically and logically correct | Reviewer or executable validation | Yes |
| Explanation | Explanation justifies the answer and addresses distractors | Review sample and audit | Yes |
| Option quality | One best answer; no accidental clues or multiple correct choices | MCQ review | Yes |
| Difficulty | Target distribution is defined and achieved | Distribution report | No, unless extreme |
| Coverage | All chapter/topic areas represented | Coverage matrix | Yes |
| Duplicates | Near-duplicates below agreed threshold | Similarity report | No, until threshold breached |
| Practical validity | Code, SQL, formula, or case task has expected result or criteria | Test artifact | Yes |
| Safety | No secrets, harmful instructions, or unauthorized personal data | Safety scan | Yes |
| Language | Clear, unambiguous, and level-appropriate | Editorial review | No |

## Recommended distribution for 200 items

- 40 beginner concept items
- 50 intermediate application items
- 40 advanced reasoning items
- 25 troubleshooting items
- 25 practical implementation items
- 20 scenario and judgment items

The distribution may change only through a documented module contract change.
