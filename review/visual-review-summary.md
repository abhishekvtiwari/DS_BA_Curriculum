## Book-wide visual themes (one decision each)
1. Draft/approval badges, versions and dates on every cover; labels inconsistent (Draft / Draft v4 / v1.1 / Approved v1/v2); cover rule strikes Part label text (Ch 28–34, 63–67).
2. Contents pages have no page numbers (all 85).
3. Figure text 3–6.9 pt (<7 pt print minimum) in 64 chapters; figures drawn ~1.7× too wide.
4. Figures contradicting text or overlapping/clipping themselves (Fig 17.1, 24.1–24.4, 25.5, 33.1, 40.2, 49.2, 50.1, 59.2, 64.1 and others).
5. Figures out of number order (14 chapters).
6. Colour-only meaning, red/green (19 chapters).
7. Page breaks: half-empty pages (54 ch), stranded lead-ins/headings/answer numbers (53 ch); code blocks never split.
8. Code lines wrap to column 0 without continuation (52 ch); output tables misaligned by wrapping.
9. Two-digit list numbers clipped ("l8.") (35+ ch).
10. Tables: mid-token wraps (IDs "Q72A-/003"), short tables split, numbers left-aligned, white-on-white headers (Ch 11, 12, 27), tables set as mono text (Ch 63, 65), raw "|" table (Ch 56).
11. Rendering: "$" read as maths (Ch 49, 54); maths glyph faults (Ch 30, 35); raw markup printed (Ch 11, 82); ₹ font fallback.
12. Scale/resolution: Ch 19 printed at ~77%; low-ppi rasters (Ch 15, 20, 53).
13. Ch 12 §12.13: PostgreSQL and MySQL versions of a block often unlabelled.
