# Ch 17 — Python from Zero
Verdict: The content is correct and well chosen. The outputs almost all match the code, Riverstone numbers reconcile to Ch 10–11 (₹4,335,471), and the error-handling and "getting unstuck" material is excellent. But as the reader's **first programming chapter** it fails the Jupyter line-by-line test badly. Most blocks introduce 5–10 new ideas at once. Loops, `+=`, tuple unpacking, keyword arguments, methods, `with` and `repr` are used before they are explained. The very first REPL block's output is wrong. The terminal, venv activation and notebook setup are assumed rather than taught. §17.14 writes a script as a Python string and runs it through `subprocess`, which hides the real workflow from a beginner. It needs the new §17.0 and a cell-by-cell rebuild of §17.4–17.14. The prose can mostly stay.
Size: ~1,110 lines, ~24 pages (pp. 270–293). Time needed stated: 25–30 hours over 3–4 weeks. Plausible? Yes for the hours: this is a full beginner Python course. Adding §17.0 (about 2 h) and splitting blocks into cells makes 28–32 hours more honest. The per-section load is the real problem: §17.5–17.13 each introduce 8–15 new constructs, and the Key terms list has about 85 entries (17.39).

## What works (keep)
- Every Python concept is tied to something the reader already knows: `strip()` ↔ TRIM, dict ↔ XLOOKUP, set difference ↔ anti-join, `DictReader` text values ↔ Ch 14 staging tables, to_float + bad_rows ↔ Ch 14 quarantine.
- The data is small and checkable: 12 monthly CSVs of the 330 key-account lines, total ₹4,335,471.00, the same figure as Ch 10/11/13. The reader can prove their script is right.
- §17.12 (tracebacks bottom-up, the "first month" error table, try/except with "catch what you expect", count and report failures) and §17.15 (getting unstuck, AI as a colleague you check) are outstanding for beginners.
- Outputs recompute: every arithmetic, list, dict, set, string, date and statistics output tested matches the code, except the REPL block (17.2) and the logging block (17.26).
