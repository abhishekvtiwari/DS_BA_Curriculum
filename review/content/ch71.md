# Ch 71 — SQL Question Bank
Verdict: A strong, realistic question bank. The NULL, fan-out, tie and window-frame traps are the right ones, and every Riverstone number I could check reconciles with Ch 12–13 (monthly revenue, month-over-month changes, the 11 NULL reps, 175 orders from 23 customers, order 5006's ₹14,640 doubling to ₹29,280). But it is not yet safe to hand to a reader. Three drafting leftovers are still visible ("this chat doesn't have…", "not re-verified … in this checker", "Note the fix mid-draft … re-verification step"). Four interview answers are factually wrong: MySQL's default isolation level, PostgreSQL's TRUNCATE "resets auto-increment", CURRENT_DATE "needs the engine-specific function", and a top-N output that shows a column the query doesn't select. The claim that "every single query" ran on MySQL 8.0 doesn't hold: about a third of the blocks are PostgreSQL-only, and the CASCADE demo uses the inline `REFERENCES` form that Ch 12 warns MySQL silently ignores. Several "Learn it in" pointers send the reader to chapters that don't teach the topic (recursive CTE, EXPLAIN/indexes, views, ACID, retention, STRING_AGG). Isolation levels, dirty reads, deadlocks and MVCC are taught nowhere in the book.
Size: ~1,650 extracted lines, 31 pages (Part VIII pp. 56–86). 81 question IDs (Q71-001…073 plus 047B/C/D). 32 code blocks, plus inline snippets in the rapid-fire tables. Time needed stated: none. Plausible? Not stated. For a revision bank that is acceptable, but add one: about 6–8 hours to work every core question hands-on in both engines, and 1–2 hours for a read-through revision pass.

## What works (keep)
- Every core question has the same shape: memory hook → one-line answer → Passes/Strong/Extra tiers → follow-ups → red flag → pointer. It maps directly onto Ch 69's rubric and is easy to revise from.
- The traps are shown live, not described. NOT IN returns 0 vs 2 (reproduced in SQLite on the mini data: 0 and 2 ✓). The fan-out doubles order 5006 from ₹14,640 to ₹29,280 (reproduced ✓). RANK/DENSE_RANK are shown on real ties (Sharma Hardware and Metro Mart at 16). EXPLAIN chooses a Seq Scan on a 175-row table.
- The results are honest. The empty duplicate check, 2-day-only streaks, "Furniture/Industrial show one row" and a real negative April change are kept rather than swapped for prettier data. This models Ch 69's Move 7 well.
- Q71-047D (one-query table profile) and Q71-045 (fan-out walk-through) are excellent interview material. They tie back to Ch 12's fan-out and Ch 13's Pattern 10.
