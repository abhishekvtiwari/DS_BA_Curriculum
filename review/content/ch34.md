# Ch 34 — The Command Line, Linux & Networking Basics
Verdict: The chapter is excellent on the parts that belong only to it: pipelines that reconcile to the book's own totals (₹439,823.50 for December, ₹4,335,471 for the year), the NR/FNR bug shown on real output, permissions, `set -euo pipefail`, and a disk-full incident told over SSH. Under Decision D2, its first two sections (opening a terminal, navigation, paths, make/copy/move/remove) now live in Ch 26 §26.0. Ch 34 must open with a recap instead, and its "Before you start: Chapter 6 … made a virtual environment" line must go. Beyond the split, three things block a first-time reader. The SSH section can't be followed because no server exists and none is set up. Windows readers are told Git Bash mostly works, but `chmod`, `ss`, `sudo`, `getent` and `rsync` don't. There are also in-chapter ordering problems: pipes and grep appear before §34.3–34.4, and the log narrative contradicts the practice data.
Size: ~1,210 extracted lines, 31 pages (pp. 253–283). Time needed stated: 10–14 hours over two weeks. Plausible? Roughly, but it should change. The split removes about 1.5–2 h of basics. Setting up WSL (Windows) and a local SSH server adds about 45 min. The heavy one-liners need splitting (34.10). New estimate: 9–12 hours, in three sittings: (1) §34.0–34.4 text tools; (2) §34.5–34.7 permissions, environment and scripts; (3) §34.8–34.9 plus the project.

## What works (keep)
- Figure 34.2 and the stage-by-stage "How it works" for `cut | tail | sort | uniq -c | sort -nr | head`, with "Forgetting the sort before uniq is the classic mistake", and the ✓ cross-check that Pune's 42 matches `grep -c`.
- §34.4's deliberate NR vs FNR bug: the reader sees the stray `category 0.00` line, learns why, and learns that awk treats text as 0 ("exactly the kind of silent nonsense to watch for"). Reconciling December by category (220,363.50 + 142,180.00 + 77,280.00 = 439,823.50) to Ch 29's report is exemplary.
- §34.7's `daily_summary.sh` run through all four outcomes (data, empty day, missing file → exit 2, no argument → exit 1), and the "shell scripts stop being the right tool sooner than you think" warning.
- "In the real world: the disk that filled up at 2 a.m." The df/du/find sequence is realistic, checks before deleting, and its numbers are internally consistent (61 × 412 MB ≈ 25 G; 15 G/40 G = 38 %).
