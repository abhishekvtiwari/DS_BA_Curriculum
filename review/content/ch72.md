# Ch 72 — Python & pandas Question Bank
Verdict: Good question choice with a clear, honest format. I re-ran every Python snippet (Python 3.11, pandas 3.0.2), and the core Python outputs are all correct (mutable default, late binding, int base, float, `**`, and/or, grid aliasing, all 14 rapid-fire snippets). The chapter isn't yet ready for a reader. All 20 "Learn it in" pointers say "Chapter 72's own fundamentals/pandas section", which is self-referential, plus a drafting note ("this chat doesn't have…"). The pointers should name Ch 17, 18, 29 and 33. Roughly half the Python questions test things the book never teaches: mutable defaults, copy/deepcopy, closures, `*args/**kwargs`, decorators, walrus, keyword-only args. Two pandas answers are wrong for the pandas 3.0.2 the chapter pins. Chained assignment doesn't "just work": it never updates `df`, and pandas warns `ChainedAssignmentError`.
