# Ch 70 — Excel, Google Sheets, VBA & BI Question Bank
Verdict: A dense, well-chosen bank. Most model answers are correct and interview-realistic, the "Remember it as" hooks are memorable, the broken-code questions (infinite loop, re-sending emails) are exactly what live rounds use, and the dashboard critiques are strong. But it isn't ready for a reader: (1) the opening box is a drafting/status note ("this chat doesn't have those chapters' approved text", "see the status report", "weren't executed live in this environment") and the "Learn it in" pointers were never checked; several are wrong (SUMPRODUCT → Ch 10, fan-out → Ch 13, "Chapter 5 … pending", star schema → "Part V"); (2) the "6-row Riverstone practice table" behind every quoted result (1,894; 90; 7,674; 850) is never printed, so no answer can be reproduced; (3) four model answers are wrong: the pivot "Item2" label (Excel shows "(blank)"), the Min/Max calculated field (calculated fields always work on sums), conditional-formatting precedence (the top rule wins, not the last), and Append = UNION (it's UNION ALL); two more are doubtful (Top-N ties, SpreadsheetApp.flush); (4) no difficulty or level labels, no Time needed, no pointers on the 46 rapid-fire rows, and move tags that don't match Ch 69's twelve.
Size: 1,089 extracted lines, about 19 pages (pp. 37–55). 70 questions (Q70-001–070): 22 core, 46 rapid-fire, 2 dashboard critiques; 9 code blocks (VBA ×2 broken/fixed pairs, Apps Script ×2 pairs, DAX ×1, plus inline formulas). Time needed stated: none. Plausible? n/a. Add "Time needed: 4–6 hours for a first pass (about 5 minutes per core question, 1–2 per rapid-fire row); 1 hour for the final-week list."

## What works (keep)
- The compact core-question format (hook, one-line answer, Passes/Strong/Extra table, follow-ups, red flag, pointer) is fast to revise from and matches Ch 69's tiers.
- Q70-041 (VBA infinite loop + Integer→Long) and Q70-053 (Apps Script duplicate emails, with a "run it twice, expect zero" check) are realistic, correct, and I confirmed Q70-053's fix in a mock run.
- Q70-069/070 dashboard critiques: problem → why → fix tables are concrete and line up with Ch 15's rules (3D pies, sorted bars, one palette) and Ch 16's (avoid gauges, Import over DirectQuery).
- The final-week list (20 IDs) is a good closing device; all 20 IDs exist.
