# Ch 14 — Data Cleaning & Preparation
Verdict: A good method: load as text, profile, fix, validate, reconcile, document. It uses a very well built dataset: every number I recomputed ties out, from the 25,976 raw rows down to ₹311,797.50 explained. The branch league-table story is one of the best in Part II. For a first-time reader, though, the SQL half is shown as results, not as teaching. Regular expressions are used from §14.2 onward and never taught. The actual cleaning pipeline (the `typed` step, y/m/dd date parts, `clean_order_lines`, `clean_customers`, `dq_order_issues`) exists only in a companion script and is used before it is built. Several key blocks are fragments that cannot be run. Loading starts with terminal commands (M.4). pandas appears across the chapter, not only in §14.13 (M.2).
Size: ~1,640 lines / 32 pages (pp. 188–219), ~45 code/formula blocks across SQL, M, Excel and Python, plus 30 exercises, a project and a 40-minute challenge. Time needed stated: 20–25 hours over three weeks; plausible? Only at the top end, and only if each topic is taught in one tool first (see 14.24). Every topic is currently taught in three to four tools.

## What works (keep)
- The dataset design: damage planted in documented ways, an answer key, and a truth table let the reader *prove* the clean result (25,832 lines, 25,812 identical, ₹423,561,010.50 + ₹311,797.50 = ERP total). This is reconciliation taught by doing.
- Traps shown with real output and a business consequence: "Rs. 430 → .430" (naive strip), MySQL's case-insensitive GROUP BY hiding 18 spellings (21,185 vs 19,835), the 97.9% match rate hiding all 533 Kolkata failures, the footer's row count that "lies", and `DATE(2025,11,31)` silently becoming 1 December.
- Figure 14.2 (four decisions for a missing value) and the cleaning log table (rule, rows, decided by, why) are exactly what a working analyst needs.
- "In the real world: the branch league table": every figure recomputes, errors run in both directions (Kolkata overstated), and it ends with fixing the process.
