01 · The Interview Book

Be Interview Ready is the front of everything. Sixteen question banks, 1,160 questions, each one with a one-line answer, a three-tier model answer, the likely follow-ups, the red flag, and where in the volumes the idea is taught. It stands on its own: a reader who buys nothing else still gets a complete book.

02 · Add-on: The Volumes

The volumes are where the interview book's "Learn it in" pointers lead. Buying them turns the interview book from a rehearsal into a course.

  • Volume 1, Theory (Parts 0 and 1). What data is, how a business runs on it, numbers without fear, thinking like an analyst, and the map of data jobs and how skills unlock them. No software needed.
  • Volume 2, Practical (Parts 2 and 3). Spreadsheets, SQL, data cleaning, charts, Power BI, Python, statistics and business skills, then advanced SQL and data modelling, dbt, experiments and causal inference.
  • Volume 3, Implementation (Parts 4 to 7). Machine learning and data science, data engineering, production ML, generative AI and MLOps, and architecture, governance and leadership.
  • Practice files. Every dataset, workbook, query and script the volumes use, arranged by tool (Excel, SQL, Python and so on) rather than by chapter, each running from the smallest idea to a finished thing you can run.
  • The topic guide. Every chapter, section and term, so any topic can be found in seconds.

03 · Add-on: Projects

Ready-made portfolio projects, bought one at a time. Each is meant to carry a realistic brief, genuinely messy data, a worked and runnable solution, the reasoning behind it, and the part nobody else sells: how to talk about the project in an interview.

None is built yet. This folder holds the catalogue and the design, so the shape of the offer is visible. The first project to build is the daily report that sends itself.
