# Visual review — Ch28-Advanced-SQL-Performance-and-Data-Modeling.pdf (82 pages)
Verdict: A long, code-heavy chapter. It is set consistently, and its SQL input and psql output are clearly distinguished. The main problems come from its length. Code and query-plan lines wrap back to column 0 on about a dozen pages, and one wide psql result (p. 80) breaks into an unreadable table. All six figures sit at 4.7–6.6 pt. The answer section leaves answer numbers stranded above large blanks on five pages, and several other pages are left a third to a half empty.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 81").

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body; DejaVu Sans 8.3 pt tables; DejaVu Sans Mono 7.9 pt code (Mono-Bold and Mono-Oblique in plans). DejaVu Serif is used as a fallback for "₹", "✓" and arrows in body text on pp. 11, 13, 14, 17–20, 35, 37, 38, 44, 45, 50, 52, 66, 74, 78. No tofu.
- **Images:** none raster.
- **Figure text size** (pdfplumber): Fig 28.1 4.9–6.2 pt; Fig 28.2 5.2–6.6 pt; Fig 28.3 5.4–6.6 pt; Fig 28.4 5.5–5.7 pt (the whole plan listing); Fig 28.5 5.3–6.4 pt; Fig 28.6 4.7–6.2 pt. Figure numbers run in order (pp. 8, 12, 21, 25, 36, 39).
- **Code-wrap scan** (monospace lines reaching the block's right edge, then confirmed by eye): pp. 16, 23, 26, 27, 29, 31, 32, 61, 62, 80.
- **Text outside margins:** exercise numbers "10."–"22." at x = 47.7 pt, with the first digit clipped (pp. 68–69).

- Every page was viewed on contact sheets. All six figures, every table and all flagged code blocks were zoomed at 150–200 dpi.

## Patterns (things that repeat on many pages — describe once, list pages)
- **Code and plan wrap to column 0** (V28.2): about a dozen pages. The single biggest readability issue in the chapter.
- **Page-foot strandings and blank pages** (V28.6–V28.8): pp. 7, 18, 24, 26, 41, 46, 48, 49, 70, 73, 75, 77–79. They all come from code blocks that cannot split. One rule (allow blocks longer than about 15 lines to split, keep lead-ins with next) fixes most of them.
- **Figure text 4.7–6.6 pt** on all six figures.
- **SQL input** has a dark-blue left rule and **psql output** a grey rule, a good distinction, used consistently.
- **Callouts:** "Watch out" is peach. "Simplification note", "Dialect note", "Try it", "Interview extra point" and "Real-life example" all share the same light-blue box, distinguished only by the bold lead word.
- **Folios** "n / 81", chapter-local. The footer is correct on every page.
