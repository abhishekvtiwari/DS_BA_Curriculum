# Visual review — Ch17-Python-from-Zero.pdf (36 pages)
Verdict: Clean, consistent body typography, and the code and tables are well set. The chapter's three figures are the weak point. Figures 17.2 and 17.3 are set at 4–5 pt, and in Figure 17.1 the arrow points the wrong way. Two-digit exercise numbers are visibly clipped at the left edge. Input and output code blocks look identical. Several long code lines continue at column 0. One page is half empty.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 35").

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body (Type 3), Poppins headings, DejaVu Sans 8.3 pt tables, DejaVu Sans Mono ~7.9 pt code. "₹" and arrows ("→") fall back to DejaVu Serif / Serif-Bold in body text (pp. 6–8, 28–29, 32, 34–36). No tofu.
- **Images:** none raster. All figures are vector.
- **Figure text size** (pdftotext word boxes × 0.8): Fig 17.1 5.3–5.7 pt; Fig 17.2 4.6–5.3 pt (most at 4.6–4.7); Fig 17.3 4.0–4.6 pt (title 6.6).
- **Text outside margins:** exercise numbers "10."–"30." start at x = 48 pt, left of the 54 pt text edge (pp. 32–33). They are **clipped**: the left part of the first digit is cut off. Confirmed with both pdftoppm and pdftocairo at 300 dpi. No text beyond the right margin.
- **Blank-area scan:** p. 23 47% empty. p. 36 is the chapter end.
- **Code-wrap scan** (continuation line at the block's left edge with open brackets): pp. 10, 22, 25 (×2).
- Every page was viewed on 6-up sheets, and all 3 figures, the error and module tables, and the long script (p. 24) were zoomed at 200–300 dpi.

## Patterns (things that repeat on many pages — describe once, list pages)
- **Figures drawn too wide and scaled down** (pp. 5, 12, 19). All three text-based diagrams sit at 4–5.7 pt. This is the same root cause as Ch25–27.
- **Input/output blocks look the same** throughout. The chapter has about 45 code/output pairs.
- **Clipped two-digit list numbers** (pp. 32–33). The same happens in Ch18–22.
- **Callouts:** Watch out (peach, red rule) and Tool note (blue) are used consistently. The Chapter-at-a-glance box is the same blue.
- **Folios** "n / 35", chapter-local. The running footer is correct on every page.
