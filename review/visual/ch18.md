# Visual review — Ch18-Python-for-Analysts.pdf (36 pages)
Verdict: A code-dense chapter with no figures, and it is typographically consistent. Its most serious problem is visible content: three printed outputs are Python errors (TypeError, NameError, KeyError) where results should be. That directly contradicts the cover's claim "Every code block run and its output checked". Long lines in code continue at column 0 in about 15 places, which in Python reads as broken indentation. The same shared problems as Ch17 also appear here: identical input/output blocks, clipped exercise numbers, one half-empty page, and cover/contents labels.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 35").

Automated checks:
- **Fonts:** all embedded (same set as Ch17). "₹" and arrows fall back to DejaVu Serif / Serif-Bold (pp. 11, 16, 18, 30–36). No tofu.
- **Images:** none. The chapter has no figures, although section 18.11 is about charts. The charts its code saves are never shown.
- **Text outside margins:** exercise numbers "10."–"30." at x = 48 pt, clipped on the left (pp. 32–33).
- **Blank-area scan:** p. 22 42% empty. p. 36 is the chapter end.
- **Code-wrap scan:** continuation at column 0 on pp. 5, 6, 7 (×4), 10, 12, 15 (×4), 16 (×4), 18 (×2), 19, 21 (×2), 23 (×4), 25, 26.
- **Output scan** for error text: pp. 13, 14, 19 (see V18.1–3).
- Every page was viewed on 6-up sheets. All tables and the long script (pp. 23–25) were zoomed at 150–200 dpi.
