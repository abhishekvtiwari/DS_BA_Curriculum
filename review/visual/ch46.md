# Visual review — Ch46-Pipelines-and-Orchestration.pdf (34 pages)
Verdict: The longest code chapter in this batch, and the one with the most layout defects. All four figures are set at 5.4–7.1 pt. Two code blocks are followed by **empty output boxes**, which look like missing output. One page carries a single bullet and is otherwise 88% blank, and two more pages are 38–44% blank. The Dagster-vs-Airflow table splits with 2 rows on the next page, and its inline commands wrap mid-date ("2026-" / "01-05"). SQL-in-Python lines wrap to column 0 throughout. The callouts, the tables' header style and the memo/alert output blocks are consistent.

Page numbers below are **PDF pages**; the printed folio ("n / 33") is PDF page − 1.
