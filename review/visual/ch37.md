# Visual review — Ch37-Supervised-Learning-Algorithms.pdf (48 pages)

Verdict: The longest chapter in the batch. Code, output blocks and the three reference tables are clean and consistent. Readability suffers from three things. Formulas use caret notation ("e^−0.8", "1 + e^(−z)") instead of superscripts. Code blocks never split, so five pages run 25–35% short. Answer numbers are stranded at page feet. All three figures are at 5.5–6.6 pt. Figure 37.2 places its "best validation 0.752" label beside the wrong point.

Page numbers below are **PDF pages**. The printed folio is PDF page − 1 ("n / 47").

Automated checks:
- **Fonts:** all embedded. Lora (Type 3) body; Poppins headings; DejaVu Sans tables and figures; DejaVu Sans Mono code (about 7.9 pt). DejaVu Serif / Serif-Bold / Serif-Italic fallback appears on pp. 6, 7, 9–12, 14, 17, 30, 35, 36, 41, 42 for ₹ (×19), ✓, ₙ, ₁ ₂ and ⁵. ₹ is close to Lora in weight. ₙ in the linear-regression formula (p. 6) is visibly lighter and sits lower than ₁/₂. No tofu.
- **Images:** none raster.
- **Figure text size:** Fig 37.1 5.9–6.6 pt; Fig 37.2 5.9–6.6 pt; Fig 37.3 5.5–6.0 pt.
- **Text outside margins:** two-digit list numbers at x ≈ 47.7 pt (pp. 40, 41).
- **Blank-area scan** (last text line / page height; body ends at about 0.92): p. 30 0.60, p. 23 0.63, p. 7 0.66, p. 19 0.68, p. 6 0.69, pp. 43–45 0.77–0.80, p. 48 0.20 (chapter end).

## Patterns (things that repeat on many pages — describe once, list pages)
- **Figure text 5.5–6.6 pt** in all three figures (pp. 12, 20, 28). Line colours are orange/blue, which is safe for colour-blind readers. Lines are labelled directly, except in Fig 37.1.
- **Formula callouts** (light-blue box with a dark-blue rule) are used consistently for hand calculations (pp. 6, 10, 12, 13, 15, 17). Content set inside them uses ÷ and × symbols with caret exponents (V37.6).
- **Unsplittable code blocks** cause the short pages (V37.7) and the stranded answer numbers (V37.8).
- **Callouts:** "Watch out" (peach) and "When to use X" (light blue) are consistent across all nine algorithm sections, which is a nice touch.
- **Tables** (pp. 10, 23, 35, 36) are all DejaVu Sans with a blue header. No splits, no mid-token wraps, and no numeric columns.
- **Folios** "n / 47", offset −1.
