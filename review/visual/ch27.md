# Visual review — Ch27-Capstone-Your-Analyst-Portfolio.pdf (31 pages)

Verdict: The densest chapter for code and output. Its SQL and pandas blocks are well set, with SQL input and output visually distinguished. Two figures are unreadably small (27.1, 27.2) and a third is marginal (27.3). One table header is invisible: white text on a white code pill. Long code lines wrap back to column 0 with no continuation marker. The model memo's To/From/Date/Re header runs together as one line.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1.

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body; DejaVu Sans 8.3 pt tables; DejaVu Sans Mono 7.9 pt code. "₹" falls back to DejaVu Serif / Serif-Bold (pp. 6, 7, 8, 14, 28) because Lora lacks the glyph. The weight and shape are close enough that it is barely visible at 300 dpi. U+2212 minus renders correctly in Lora. No tofu.
- **Images:** none raster.
- **Figure text size:** Fig 27.1 3.7–5.5 pt; Fig 27.2 3.8–6.2 pt; Fig 27.3 5.4–6.1 pt.
- **Text outside margins:** list numbers "10."–"15." at x = 48 pt (pp. 26–27) only.
- **Blank-area scan:** p. 11 34%, p. 5 15%, p. 31 65% (chapter end).
- Every page was viewed, and all figures, the answer table and the long code blocks were zoomed at 200–400 dpi. Underscores in code render correctly.

## Patterns (things that repeat on many pages — describe once, list pages)
- **Figure text below print minimum** (pp. 5, 11, 19). Same root cause as Ch25/26: figures are drawn about 1.7× too wide and scaled down.
- **Code styling:** SQL input has a dark-blue left rule and query output a grey rule, which is a good distinction. Python blocks (pp. 12–13) also get the grey "output" rule, so Python input looks like output. Use the blue rule for all input.
- **Output blocks** (psql and pandas prints, pp. 6, 8, 10, 13–14, 29) are correctly right-aligned by the tools themselves.
- **Light-blue callout reused** for a quotation (p. 4), the memo (p. 16), an interview answer (p. 18) and model answers (pp. 29, 30), the same style as Chapter-at-a-glance. No Watch out / Try it / Interview extra point callouts appear in this chapter.
- **Page-foot strandings** (lead-in or answer number left behind): pp. 7, 11, 29. A global keep-with-next for "…:" lead-ins and answer numbers would fix all of them.
- **Folios** "n / 30", chapter-local.
