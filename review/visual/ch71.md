# Visual review — Ch71-SQL-Question-Bank.pdf (33 pages)
Verdict: The SQL, psql output and tier tables are set cleanly, and the live-verified results are a strength. Structurally, though, the chapter is scrambled on the page. The rapid-fire headings carry the wrong section numbers ("Rapid-fire, 71.9" sits inside 71.2), and question IDs run 001–008, then 047–060, then 009…, so a reader cannot navigate by ID. The chapter-at-a-glance repeats the "this chat doesn't have…" production note. Long SQL lines wrap to column 0, several lead-ins and "Extra points" rows are stranded across page breaks, and the cover subtitle ends in "top N…".

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 32").

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body; DejaVu Sans 7.5–8.3 pt tables (minimum 7.0 pt); DejaVu Sans Mono 7.6–7.9 pt code and output. "₹" (pp. 14, 16, 18, 19, 27, 29) falls back to DejaVu Serif. No tofu.
- **Images:** none. No figures.
- **Text outside margins:** none.
- **Blank-area scan:** p. 2 (contents) 56 %; p. 33 73 % (chapter end, "Where this leads" only).
- Every page was viewed. All code blocks, psql outputs, tier tables and rapid-fire tables were checked, and the wraps and splits were zoomed at 150–170 dpi.
