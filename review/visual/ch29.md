# Visual review — Ch29-Python-as-Software-Not-Scripts.pdf (43 pages)
Verdict: Clean prose, and the four figures are well designed, but all of them are drawn at 5.2–6.6 pt. On p. 22, Figure 29.3 is printed above Figure 29.2. The page breaks around big code blocks leave p. 7 three-quarters empty and p. 27 half empty.

## Patterns (things that repeat on many pages — describe once, list pages)
- **Column-0 code wraps** on about 20 pages (V29.4). This chapter teaches code style, so wrapped comments without "#" are especially misleading.
- **Page-break strandings and blank pages** around long code blocks (pp. 4, 7, 9, 13, 23, 25, 27, 35, 39, 40).
- **Code input and output** both use a grey-blue left rule. Terminal sessions, Python source and program output look the same. Ch28's darker rule for input would help here.
- **Callouts:** "Watch out" is peach (pp. 10, 13, 16, 26, 31). "Simplification note", "Tool note", "Python link" and "Real-life example" share the light-blue box.
- **Folios** "n / 42", chapter-local. The footer is correct.
