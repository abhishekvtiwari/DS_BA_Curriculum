# Visual review — Ch60-Designing-Whole-Systems.pdf (22 pages)

Verdict: This is the first "Approved" chapter in the batch. It has no code and five architecture figures, which carry most of the chapter. Those figures have the batch's worst drawing faults:
- **Clipped titles.** Figure 60.3 cuts off its box titles ("emantic layer (dbt-style model").
- **Labels over icons.** Figure 60.2 prints actor labels on top of the person icons.
- **A contradicted arrow.** Figure 60.2's ERP arrow never reaches the platform, although the figure's note says every arrow crosses the boundary.

All figure text is 4.2–6.9 pt. The cover label scheme ("Approved chapter v1") differs from Ch55–59 ("Draft chapter").

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 21").

Automated checks:
- **Fonts:** all embedded. No DejaVu Serif fallback (₹ appears only inside DejaVu Sans figures and tables). No tofu.
- **Images:** none raster.
- **Figure text size:** Fig 60.1 (p. 5) 4.8–5.7 pt; Fig 60.2 (p. 6) 4.2–6.6 pt; Fig 60.3 (p. 7) 5.3–6.9 pt; Fig 60.4 (p. 8) 5.4–6.1 pt; Fig 60.5 ADR (p. 9) 5.4–5.6 pt.
- **Text outside margins:** exercise numbers at x = 48 pt (p. 19).
- **Blank-area scan:** p. 6 62%, p. 22 27% (chapter end).
- Every page was viewed; all five figures and all tables were zoomed at 150 dpi.

## Patterns (things that repeat on many pages — describe once, list pages)
- **Figure text below 7 pt** on all five figures (pp. 5–9); four of them are on consecutive pages.
- **Figures drawn with fixed-size boxes** whose titles overflow (p. 7) or whose bodies are mostly empty (pp. 5, 9).
- **Tables:** header style is consistent; splits repeat the header (pp. 10→11, 11→12).
- **Callouts:** one Watch out (p. 9).
- **Folios:** "n / 21", chapter-local.
