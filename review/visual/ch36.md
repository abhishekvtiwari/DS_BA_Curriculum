## Patterns (things that repeat on many pages — describe once, list pages)
- **Figure text 4.6–6.4 pt** in all five figures (pp. 9, 10, 15, 24, 28). Same cause as the pilot: the figures are drawn wide and scaled down. Colours are blue / teal / orange / red, with no red–green pair. Bars carry direct value labels, so greyscale is OK.
- **Page breaks before long code blocks** leave big blanks (pp. 8, 13, 16, 20) because code blocks are never split. A "split blocks longer than ~15 lines" rule would fix most of them.
- **Answer numbers stranded at the page foot** (pp. 35–39). The answer number is set as its own paragraph ("5.") followed by a code block, so it has no keep-with-next.
- **Callouts:** "Watch out" (peach, orange rule), "Real-world note" / "When scaling doesn't matter" (light blue) and the quote callout (p. 29) are used consistently.
- **Input vs output code:** input and output blocks both use a grey left rule with the same background and differ only by a gap. It is readable but not distinct (pp. 5–6, 14, 24–27, 36–40).
- **Folios** "n / 40", chapter-local, offset −1.
