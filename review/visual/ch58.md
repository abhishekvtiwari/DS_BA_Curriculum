# Visual review — Ch58-Intelligent-Automation.pdf (25 pages)

Verdict: The chapter is solid and table-heavy; the tables are clean and consistently styled. The main problems:
- **Figure 58.1 misroutes its flow.** Its dashed connector sends validation failures to the approval box, and the "held for review" box has no connector.
- **Small figure text.** All three figures are 4.9–6.5 pt.
- **Blank page ends.** Three pages end about a quarter empty because a figure or code block would not split.
- **Code wrapping.** Long SQL/Python lines wrap to column 0.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 24").

Automated checks:
- **Fonts:** all embedded. "₹" falls back to DejaVu Serif / Serif-Bold on pp. 8, 9, 19, 20, 22, 24. No tofu.
- **Images:** none raster.

- **Text outside margins:** exercise numbers at x = 48 pt (pp. 18, 20).
