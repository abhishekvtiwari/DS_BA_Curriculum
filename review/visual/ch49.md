# Visual review — Ch49-Storage-Warehouses-and-Lakehouses.pdf (22 pages)
Verdict: A clean, well-paced chapter with good tables. Two money passages are broken: "$" was parsed as a TeX math delimiter, so the worked cost estimate (p. 14) and answer 9 (p. 21) print garbled italics and stray asterisks. Figure 49.2's arrows point at the wrong files. Both figures are below 7 pt. Long code lines wrap to column 0, and one wrap splits the string literal 'M-07'.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 21").

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body; DejaVu Sans Mono 7.9 pt code; DejaVu Sans 7.5 pt footer. "₹" (p. 14) falls back to DejaVu Serif. No tofu.
- **Images:** none raster.
- **Figure text size:** Fig 49.1 (p. 5) 4.5–6.9 pt; Fig 49.2 (p. 9) 5.2–6.6 pt.
- **Text outside margins:** none, apart from the two-digit exercise numbers (V49.9).
- **Blank-area scan:** p. 2 (contents) 51%; p. 8 about 35% (V49.6); p. 22 chapter end.
- **Garbled maths:** found by reading pp. 14 and 21 at 150 dpi.
- Every page was viewed on 3×2 contact sheets at 70 dpi. Both figures, all tables and the code blocks on pp. 6–12 were zoomed at 150–400 dpi.

## Patterns (things that repeat on many pages — describe once, list pages)
- **"$" parsed as maths** (pp. 14, 21). Same root cause as Ch54: any paragraph with two "$" signs is broken.
- **Code wraps to column 0** (pp. 9–12).
- **Two-digit list numbers clipped** (p. 19). Seen in every chapter of this batch.
- **Figure text below 7 pt** (pp. 5, 9).
- **Tables:** consistent house style with dark-blue header and zebra rows. No numeric columns, so alignment does not apply. No tables are split across pages.
- **Callouts:** "Watch out" (peach), "Simplification note" (light blue) and "Chapter at a glance" are consistent.
- **Folios** "n / 21", chapter-local. The running footer is correct on every page.
