# Visual review — Ch52-The-Cloud-Containers-and-Infrastructure-as-Code.pdf (29 pages)
Verdict: A clear, honest chapter. The note on what is and isn't executed is well placed, and the three figures are tidy. The main problems are pagination: three pages are mostly empty (pp. 11, 14, 17) because long YAML/HCL blocks refuse to split. YAML and HCL lines also wrap to column 0, which changes their meaning, and a copied YAML would break. Figure text is 5.5–7.1 pt.
