## Patterns (things that repeat on many pages — describe once, list pages)
- **All six diagrams are too small** (5.1–6.5 pt). Same root cause as the other chapters: drawn wide and scaled into the text block.
- **Code styling:** SQL check queries have the dark-blue input rule, but **DAX measure blocks** (pp. 9, 11, 13, 14, 19, 21, 22, 24, 34) use the grey rule that marks output elsewhere. DAX input therefore looks like output. Use the blue rule for all input.
- **Tables** (licences, modes, calculated column vs measure, filter functions, common mistakes, tool comparison) are consistent. "Common mistakes" splits across pp. 24–25 with a repeated header.
- **Callouts** (About screenshots, Tool note, Watch out) are consistent.
- **Folios** "n / 34"; the running footer is correct.
