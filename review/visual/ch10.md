# Visual review — Ch10-Spreadsheet-Fundamentals-Excel-and-Google-Sheets.pdf (49 pages)
Verdict: A clean, well-paced chapter. Tables, callouts and formula blocks are set consistently, and there is no invisible or garbled text. Three things let it down. Two-digit exercise numbers (10–29) have their first digit clipped at the left edge. All five figures are drawn too wide, so their text prints at 5.2–6.7 pt. Long SUMIFS formulas wrap to column 0 in the middle of a string literal. The rest is draft labelling and polish.

Page numbers below are **PDF pages**; the printed folio ("n / 48") is PDF page − 1.

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body; DejaVu Sans 8.3 pt tables; DejaVu Sans Mono 7.6–8.6 pt code. "₹" falls back to DejaVu Serif / Serif-Bold on 18 pages (4, 13, 16, 17, 19, 21, 23, 24, 31, 32, 38, 39, 42, 44, 45, 47, 48, 49). "→" and "Σ" also fall back to DejaVu Serif. The fallback glyphs match Lora closely enough to be barely visible. No tofu.
- **Images:** none raster; all figures are vector.
- **Figure text size** (pdfplumber char sizes): Fig 10.1 5.2–5.9 pt; Fig 10.2 5.3–6.3 pt; Fig 10.3 5.7–6.4 pt; Fig 10.4 5.2–6.6 pt; Fig 10.5 5.4–6.7 pt.
- **Text outside margins:** list numbers "10."–"29." start at x = 47.7 pt (pp. 44–45), and their first digit is visibly clipped (V10.1).
- **Blank-area scan:** p. 2 39% (contents), p. 20 17%, p. 25 15%, p. 49 36% (chapter end). No half-empty mid-chapter pages.
- **Prescan hyphen breaks** (pp. 23, 40, 45, 48): all are ordinary compound words ("non-cancelled", "zero-padded", "co-authoring", "end-of-month"), so none is a problem.
- Every page was viewed on 3×2 contact sheets. All figures, tables and formula blocks, plus the exercise lists, were zoomed at 150–300 dpi.

## Patterns (things that repeat on many pages — describe once, list pages)
- **Figure text below print minimum** (pp. 6, 10, 12, 18, 41). Same root cause as the pilot: figures are drawn about 1.3–1.5× too wide for the text block and scaled down. Every figure in the chapter is affected.
- **Exercise number clipping** (pp. 44–45). This is not just a hanging marker: the first digit is cut. It affects every chapter with ≥ 10 exercises (see Ch11, Ch12).
- **Formula wraps to column 0** (pp. 23, 47). Watch for this wherever a `"<>Cancelled"` or `"<="&DATE` criterion lands at a line end.
- **Short tables split with 1–2 rows over the page** (pp. 8–9, 23–24, 34–35, 35–36). The header row is repeated correctly each time.
- **Callouts:** Watch out (peach), Try it / Tool note / Spreadsheet link / SQL link / Interview extra point (light blue) and Simplification note (blue) are styled consistently. Watch-out titles are bold.
- **Folios** "n / 48", chapter-local. The running footer is correct on every page.
