# Visual review — Ch65-FinOps-The-Economics-of-Data-Platforms.pdf (19 pages)
Verdict: The two matplotlib charts are readable, but the first pandas output (p. 6) is a wrapped `to_string` dump. Its "notes" column breaks onto separate lines, so the chapter's core cost table cannot be read. The figures say "Rs" while the prose uses "₹". Fig 65.2's value label collides with its title. Fig 65.3's text is small. The cover title breaks badly ("FinOps: / The / Economics…"), and a one-word widow ("decision") opens p. 17.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 18").

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body; DejaVu Sans Mono 7.9 pt code. "₹" is used on 15 of 19 pages and falls back to DejaVu Serif / Serif-Bold / Serif-Italic. The italic fallback in the Fig 65.2 callout (p. 8) is slightly heavier than Lora Italic but acceptable. No tofu.
- **Images:** none raster.
- **Figure text size (true pt):** Fig 65.1 and 65.2 (matplotlib) 7 pt or more, OK. Fig 65.3 5.2–6.7 pt.
- **Text outside margins:** exercise numbers "10."–"17." at x = 47.7 pt (p. 16); the "1" is clipped.
- **Blank-area scan:** p. 2 (contents) 58 %; p. 5 36 % (the output and Fig 65.1 moved to p. 6); p. 19 51 % (chapter end).
- Every page was viewed. All figures and all code/output blocks were zoomed at 130–220 dpi.
