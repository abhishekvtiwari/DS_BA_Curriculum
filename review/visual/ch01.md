The project's ASCII spending log wraps every row back to column 0, which breaks the one table readers are asked to copy. The usual draft cover, contents without page numbers and a few stranded lead-ins also appear.

Page numbers below are **PDF pages**. The printed folio ("n / 22") is PDF page − 1.

## Patterns (things that repeat on many pages — describe once, list pages)
- **Figure text below print minimum** (pp. 5, 6, 9, 11): every figure is drawn wide and scaled to the text block, giving 4.9–6.2 pt.
- **Stranded lead-ins and widows:** pp. 6, 6→7, 16→17.
- **Callouts** are consistent: Try it (light blue, blue rule), Watch out (peach, orange rule), Real-life example (light blue). Chapter-at-a-glance is the same light blue as Try it.
- **Code/output blocks** use grey fill with a left rule; the ASCII tables on pp. 13, 19 fit, and only the p. 17 block overflows.
