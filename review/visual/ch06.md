# Visual review — Ch06-Setting-Up-to-Learn.pdf (23 pages)
Verdict: A practical, well-organized setup chapter. Commands and outputs are set cleanly, and query input (dark rule) is kept distinct from output (grey rule). The three figures (toolkit, six-month plan, weekly rhythm) sit at 5.0–6.8 pt. The worst layout faults are a quarter-page gap after the 6.8 heading, a lead-in stranded above the venv commands, and an exercise expression "ROUND(45E-1)" broken at the exponent.

Page numbers below are **PDF pages**. The printed folio ("n / 22") is PDF page − 1.
