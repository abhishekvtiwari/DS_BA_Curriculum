# Visual review — Ch63-Automation-Architecture-and-Governance.pdf (23 pages)
Verdict: The body text, the two HTML tables and the chapter structure are clean. All four figures are set far below print size (3.7–6.8 pt), and Figure 63.4 truncates its own example text with "…". The worked ROI comparison on p. 6 is set as a monospace text dump whose wrapped cells scatter across lines, so it cannot be read as a table. The cover's decorative rule strikes through the Part label.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 22").

## Patterns (things that repeat on many pages — describe once, list pages)
- **Figure text far below print minimum** on every figure (pp. 6, 8, 10, 12). The root cause is the same as in Ch25–27: figures are drawn about 1.8× too wide and scaled down.
- **Box-and-arrow figures with large empty box interiors** (pp. 8, 10). Fixed-height boxes hold 1–2 lines of text.
- **Two-digit list numbers clip into the margin** (p. 20). The same defect appears in Ch 64, 65, 66 and 69.
- **Answers section** (pp. 21–23) uses bold run-in numbers, consistent with Ch 64–66.
- **Callouts:** only "Chapter at a glance" (light blue) appears. There are no Watch out / Try it boxes in this chapter.
- **Folios** "n / 22", chapter-local. The footer title matches the chapter.
