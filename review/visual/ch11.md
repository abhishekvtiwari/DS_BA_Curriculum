# Visual review — Ch11-The-Spreadsheet-Mastered-Excel-and-Google-Sheets.pdf (63 pages)
Verdict: The richest chapter so far, and mostly well set. It has four defects where content is garbled or hidden. Two rows of the text-functions tables are broken because a `|` inside a formula split the table. A table header is white-on-white. A paragraph in the real-world story shows raw Markdown after an unescaped backtick in "Ctrl+`". Exercise numbers 10–43 are clipped. All eight figures print at 5.1–6.7 pt. Long formulas wrap to column 0 mid-string.

Page numbers below are **PDF pages**; the printed folio ("n / 62") is PDF page − 1.

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body; DejaVu Sans 8.3 pt tables; DejaVu Sans Mono 7.4 pt for code blocks, 7.1 pt for some one-line formula blocks (p. 5, p. 7) and 8.0 pt inline. "₹" falls back to DejaVu Serif / Serif-Bold (the same pattern as Ch10). No tofu.
- **Images:** none raster.
- **Figure text size:** Fig 11.1 5.6–6.4 pt; 11.2 5.1–6.3; 11.3 5.3–6.3; 11.4 5.1–6.3; 11.5 5.1–6.2; 11.6 5.3–6.6; 11.7 5.4–6.6; 11.8 5.2–6.7.
- **Text outside margins:** list numbers "10."–"43." at x = 47.7 pt (pp. 56–58), clipped (V11.5).
- **Blank-area scan:** p. 2 45% (contents), p. 10 19%, p. 18 24%, p. 30 35%, p. 63 25% (end).
- **Markdown leak scan** (backticks and `**` in extracted text): hits on p. 11 (TEXTSPLIT), p. 12 (REPT) and p. 52 (Ctrl+`). "Ctrl+`" renders correctly in tables on pp. 43–44.
- **Prescan hyphen breaks** (pp. 3, 20, 21, 30, 54, 58): all are ordinary compounds, so none is a problem.
- Every page was viewed on contact sheets. All figures and every table and code block were zoomed at 150–300 dpi.

## Patterns (things that repeat on many pages — describe once, list pages)
- **Markdown/escaping failures** (pp. 11, 12, 52). A `|` inside a formula breaks a table row, and a backtick in "Ctrl+`" breaks a paragraph. Any row or paragraph with pipes or backticks in code needs escaping. Search the other chapters for `REPT("|"`, `TEXTSPLIT`, `Ctrl+``, and `||` (SQL concatenation in tables).
- **White-on-white code pills in table headers** (pp. 12–13). Same root cause as Ch27 V27.1 and Ch12 V12.1: one CSS fix covers all of them.
- **Figure text below print minimum**: all 8 figures (pp. 6, 14, 19, 24, 28, 36, 46, 48).
- **Formula wraps to column 0** (pp. 7, 8, 10, 25, 49). The formula blocks are set at 7.1–7.4 pt to squeeze long lines, but they still wrap.
- **Short tables split over the page** (pp. 12–13, 21–22, 41–42, 43–44). The header is repeated each time.
- **Callouts** are consistent: Watch out (peach), SQL link / Tool note / Interview extra point / Try it / Hints (light blue), Simplification note (blue).
- **Folios** "n / 62". The running footer ("Chapter 11 · The Spreadsheet, Mastered: Excel & Google Sheets") is correct throughout.
