# Visual review — Ch23-Business-Acumen-KPIs-and-Metrics.pdf (30 pages)
Verdict: The chapter is cleanly set, and its metric tables are consistent: every split table repeats its dark-blue header. All four figures fall below the 7 pt print minimum, and the P&L waterfall (Fig 23.2) is the worst at 4.6–5.0 pt. Long Python lines wrap back to column 0 in five code blocks. The first digit of two-digit exercise numbers is clipped, so "14." reads as "l4.". Almost every metric table breaks after 1–2 rows.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 29").

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body; DejaVu Sans 8.3 pt tables; DejaVu Sans Mono 7.9 pt code; Poppins headings and figure titles. DejaVu Serif, Serif-Bold and Serif-Italic are used as fallbacks for "₹" and arrows in Lora text on pp. 7, 8, 9, 14, 16, 17, 21, 23, 24, 25, 28, 29, 30. At 150 dpi this is barely visible. No tofu.
- **Images:** none raster. All figures are vector.
- **Figure text size** (pdfplumber, exact): Fig 23.1 5.1–6.3 pt; Fig 23.2 4.6–5.0 pt (axis labels and values; title 6.6 pt); Fig 23.3 5.0–5.6 pt; Fig 23.4 5.9–6.2 pt.
- **Text outside margins:** two-digit list numbers "10."–"27." start at x = 47.7 pt, and their first digit is clipped (pp. 25–26).
- **Code-wrap scan** (monospace lines reaching the right edge of the block): pp. 7, 9, 12, 13, 16.
- **Blank-area scan:** p. 2 (contents, expected), p. 20 about 18% blank before the "In the real world" page.
- Every page was viewed on contact sheets. All four figures, every table and the wrapped code blocks were zoomed at 150–400 dpi.

## Patterns (things that repeat on many pages — describe once, list pages)
- **Figure text below print minimum** on all four figures (pp. 5, 6, 15, 17). Same root cause as Ch25–27: figures are drawn about 1.5× too wide and scaled to the text block.
- **Stub table starts** at page feet (pp. 7, 9, 10, 11, 12). Headers repeat, which is good.
- **Code input and output** both use the same grey-blue left rule. Output is not visually distinct from input (pp. 5–16).
- **Callouts:** "Watch out" uses a consistent peach style with a dark-red rule (pp. 7, 11, 14). "Chapter at a glance" is light blue. No other callout types appear.
- **Rupee glyph** in body text falls back to DejaVu Serif (13 pages). The difference is barely visible.
- **Folios** "n / 29", chapter-local. The running footer is correct on every page.
