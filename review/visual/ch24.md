Verdict: The prose and tables are clean and there is no code to speak of. All four figures have real drawing defects on top of the usual 5–6 pt text. ## Patterns (things that repeat on many pages — describe once, list pages)
- **Figure text below print minimum** on all four figures (pp. 6, 7, 8, 12), 5.0–6.6 pt, plus real overprints and clipping in three of them (see V24.1–V24.3). These figures need a redraw, not just scaling.
- **Page-foot strandings:** lead-ins and headings left behind (pp. 9, 16), and a half-empty page (p. 11).
- **Callouts:** "Watch out" uses the peach style (pp. 5, 13). BLUF and memo examples reuse the light-blue "Chapter at a glance" style (pp. 7, 8, 10), as in Ch27.
- **Answer numbering** uses bold run-in numbers ("1.", "2."), unlike the list numbering of the exercises. It matches Ch23.
- **Folios** "n / 21", chapter-local. The running footer is correct.
