# Visual review — Ch51-Data-Activation.pdf (23 pages)
Verdict: The layout is sound, but the chapter's core demonstration fails on the page. Six of the Python output blocks print `NameError: name 'sl' is not defined` or `NameError: name 'scores' is not defined` instead of results. The "Reading it" paragraphs then describe numbers the reader never sees, and the cover says "Every output from a real run". Figure 51.2 has lines drawn through its labels and a clipped caption. The rest are the batch-wide faults.

Page numbers below are **PDF pages**; the printed folio is PDF page − 1 ("n / 22").

Automated checks:
- **Fonts:** all embedded. Lora 10.4 pt body; DejaVu Sans Mono 7.9 pt code. No tofu.
- **Images:** none raster.
- **Figure text size:** Fig 51.1 (p. 4) 5.7–6.4 pt; Fig 51.2 (p. 13) 5.2–6.4 pt.
- **Error scan:** grep on extracted text finds `NameError` on pp. 5, 6, 7, 8, 9, 12.
- **Blank-area scan:** p. 2 49%; p. 23 chapter end. No mid-chapter half-empty pages.
- Every page was viewed on contact sheets. Figures, tables and every code/output block were zoomed at 150–250 dpi.
