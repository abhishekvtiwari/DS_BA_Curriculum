# Data Science Pathway — Controlled Master Blueprint

**Track ID:** DS
**Artifact type:** Controlled blueprint; outlines only, not chapter prose
**Purpose:** Prevent uncontrolled generation and ensure every module, chapter, topic, and subtopic is planned before writing.

## Hierarchy

```text
Data Science pathway → Module → Chapter → Topic → Subtopic → Lesson → Lab → Assignment → Assessment
```

## Required module contract

- Module objective and entry criteria.
- Prerequisite map and exit criteria.
- Chapter inventory with stable IDs.
- Topic and subtopic inventory.
- Practical tools and environment.
- Guided labs and error-based labs.
- Assignments and answer criteria.
- Approximately 200 MCQs per module, generated only after content is audited.
- Module technical audit and completeness audit.
- Module release record.
